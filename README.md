## 📖 Vision & Scope

Designed for complete transparency, this repository documents my progression from basic syntax to advanced enterprise concepts. It serves as a technical library demonstrating:

* **📈 Quantifiable Progress:** Sequentially numbered tracking of all completed logic puzzles and projects.
* **🧠 Algorithmic Logic:** Optimized solutions for standard and advanced challenges (Codewars, LeetCode, freeCodeCamp).
* **⚡ Production-Grade Code:** Strict focus on edge-case handling, clean syntax, and optimal Big O (Time/Space Complexity).

<br/>

## 🗂️ Dual-Track Architecture

To bridge the gap between theory and execution, the codebase is split into two distinct learning tracks:

| 🧩 `/question-practice/` (The Logic Track) | 💻 `/projects/` (The Application Track) |
| :--- | :--- |
| **Focus:** Isolated algorithms and JS engine internals (Array methods, Closures, Hash Maps, Async). | **Focus:** DOM manipulation, browser APIs, and functional software development. |
| **Format:** `ques-1-reverse-string`, `ques-n...` | **Format:** `pro-1-color-flipper`, `pro-n...` |
| **Goal:** Build algorithmic muscle memory and optimize code for technical MNC interviews. | **Goal:** Translate raw algorithms into interactive, usable web modules. |
