## 📖 About

This repository is a hands-on space for practicing JavaScript, one topic at a time.

Every folder = one concept. Inside each folder, you'll find **questions to solve** and **solutions to learn from**.

It's built to grow gradually — starting from scratch and moving step by step toward advanced JavaScript, with consistent daily progress instead of a rigid, pre-planned structure.

<br/>

## 🚀 Learning path

This repo grows from **basic → advanced** JavaScript. Each new topic is added as its own folder, expanding naturally as learning progresses — no rush, just steady daily practice.
